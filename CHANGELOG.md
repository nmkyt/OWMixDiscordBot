# Changelog

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — по [SemVer](https://semver.org/lang/ru/). Текущая версия хранится в
`__version__` в [src/__init__.py](src/__init__.py).

## [Unreleased]

### Changed
- Под каждым лобби в `!create_lobby` вместо числа «Разница между командами: 30.0» выводится
  оценка баланса словами (Идеальный баланс / Ровные команды / Небольшой перевес / Заметный перевес /
  Сильный перевес). Кроме идеального баланса, указывается, какая команда сильнее и на сколько SR
  на игрока («💖 Красные — 🟡 Небольшой перевес: +45 SR на игрока»); также выводится средний
  рейтинг игрока в каждой команде.
- Виртуальное окружение теперь лежит в `.venv`, а не в `venv` (установщик, `start.bat`, `start.sh`).
  Если бот уже был установлен, запустите `python install.py` ещё раз — старую папку `venv` можно удалить.

### Removed
- Устаревшая конфигурация сборки exe-файла (`bot_controller.spec`).

## [2.4.0] - 2026-10-28

### Added
- Установщик `install.py`: создаёт виртуальное окружение, ставит зависимости и записывает `.env`
  (токен, админы, тип БД); скрипты запуска `start.bat` и `start.sh`.
- SQLite как база данных по умолчанию: если `DATABASE_URL` не задан, бот создаёт `data/owmix.db`.
  PostgreSQL работает как раньше при заданном `DATABASE_URL`.
- Пошаговая инструкция по созданию Discord-бота в README (Message Content Intent, ссылка-приглашение).
- Временные администраторы: `!admin_add discord_id` выдаёт права админа до `!mix_stop`,
  `!admin_remove` снимает их досрочно, `!admin_list` показывает всех админов. Выдавать и снимать
  права могут только постоянные админы из `ADMIN_IDS`; `!mix_stop` сбрасывает все временные права.

### Changed
- Драйвер PostgreSQL вынесен из `requirements.txt` в `requirements-postgres.txt` (и заменён на
  `psycopg2-binary`, который не требует компилятора). Для PostgreSQL ставьте
  `pip install -r requirements-postgres.txt`.
- Карты для лобби выбираются без повторов: пока не сыграны все карты из списка, ни одна
  не выпадет второй раз, в том числе между лобби одного `!create_lobby`.

## [2.3.0] - 2026-10-28

### Added
- В лог пишется, каким методом собрано каждое лобби: жадный подбор или резервный
  гарантированный алгоритм (с приоритетными ролями или по любому рейтингу).
- Версия бота хранится в одном месте (`__version__`) и выводится при старте.

### Changed
- Уточнены описания команд в `!mix_help`.

## [2.2.0] - 2026-10-24

### Added
- Команда `!mix_status`: регистрации, чек-ин, приоритетные роли, очередь, на сколько лобби
  хватает игроков и каких ролей не хватает.
- Алиас `!registration` для `!register`.
- В `!update` можно обнулить рейтинг приоритетной роли — приоритетной станет первая роль
  с рейтингом (танк, урон, саппорт).
- `!mix_help` оформлен как embed с разделами для игроков и администраторов.

### Changed
- Единый формат сообщений об ошибках для пользователя.
- Очередь больше не ограничена 10 игроками.
- Улучшено логирование; логика работы с игроками и очередью вынесена из `bot_controller`
  в `sync_logic`.

### Fixed
- Очередь больше не сбрасывается, если `!create_lobby` отказал из-за нехватки игроков.

## [2.1.0] - 2026-10-22

### Added
- Гарантированная сборка лобби: резервный алгоритм (паросочетание Куна) находит состав,
  если он математически существует.
- Точное разбиение на команды перебором всех вариантов.
- Чек-ин требует выбранной приоритетной роли.
- Администраторы задаются через переменную окружения `ADMIN_IDS`.
- Ограничения на уровне БД и набор тестов.
- В `!my_rank` показывается название ранга OW2.
- Ранг Emerald в разборе рейтинга.

### Changed
- Минимальный рейтинг снижен до 500.

### Fixed
- Права на `!mix_stop`, блокировки БД и ошибки работы с сессиями.

## [1.0.0] - 2024-11-20

Первый релиз: регистрация игроков, чек-ин, очередь, балансировка лобби, случайная карта.
